# Contributing

Thanks for stopping by. **Contributions are welcome anytime** — there is no extra process, no CLA, and no special bar.

Bugs, copy, archetypes, docs, tests, ideas: open an issue or a pull request.

## How to send a change

1. Fork and branch from `main`
2. If you touch code, run `npm test`
3. Open a PR against `main` and say what changed

Do not commit tokens, `.env` files, or other secrets.
